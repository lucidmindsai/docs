gAIa is a responsive web app — no install required. Open it in a browser on desktop or mobile and start exploring.

## Prerequisites

- A modern browser (Chrome, Firefox, Safari, or Edge)
- Optional: an account if your organisation has early access; otherwise [book a demo](https://gaia.gus.earth/#book-call)

## Get started

<Steps>
  <Step title="Open gAIa">
    Go to [ai.gus.earth](https://ai.gus.earth) and sign in if prompted.
  </Step>
  <Step title="Explore the map">
    Browse the living map of trees. Select a tree or mini forest (cluster) to open its profile.
  </Step>
  <Step title="Ask a question">
    Start a conversation. Try questions like:

    - How much carbon does this tree capture?
    - Which trees nearby need attention?
    - How might this canopy cool the street in summer?

    Answers are grounded in inventory data, species models, and GUS simulations.
  </Step>
  <Step title="Contribute (optional)">
    Add trees, photos, or observations. Every contribution strengthens the living map and tree memory over time.
  </Step>
</Steps>
